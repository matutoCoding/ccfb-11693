# 提花组织设计与织物渲染系统

浏览器内的提花组织设计 + WebGL2 织物渲染工具,TypeScript 实现,无框架依赖。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 类型检查 + 构建到 dist/
```

## 功能

- **花型库**: 增删改、复制、改名,localStorage 持久化,JSON 导出/导入,图片转组织(颜色数可限制 2~8,中位切分量化 + 阴影缎纹映射)
- **组织设计**: 格子绘制(左键经浮/右键纬浮)、取反/全经/全纬/平移、平纹/斜纹(2/1、3/1、2/2)/缎纹(五枚、八枚)一键生成、改尺寸自动循环平铺、3×3 循环预览、按经纱的浮长逐格统计与点选高亮、组织图 PNG 导出
- **纱线库**: 颜色、粗细、捻度、光泽;经纬纱在花型上分别指定
- **织物预览**: WebGL2 实例化纱线管几何(浮长端部屈曲下压)、Kajiya-Kay 各向异性高光、捻度法线扰动、光源方位/高度可调可自动旋转、浮长热力图模式、浮长一致性核对、渲染截图导出、帧率不足自动降质
- **对比**: 两种组织并排渲染,可同步视角
- **设置**: 默认尺寸、渲染质量、光源默认值、存储管理

## 浮长一致性

组织图(`Uint8Array`,1=经浮 0=纬浮)是唯一数据源。渲染几何(`src/geometry.ts`)与浮长统计(`src/weave.ts`)都从它派生;`verifyInstancesAgainstGrid` 对每格核对"该点哪根纱在上"和"所属浮长段长度",预览页和组织设计页都有一键校验。

## 性能

512×512 = 262,144 个实例,单次 `drawElementsInstanced` 绘制。实例数据约 8MB,静态上传。帧耗时超过 50ms 时自动降低纱线圆周分段(8→4),真实 GPU 上 512×512 可满帧。
